# 世の動きを読む四つの軸

政治と暮らしの動きを、四つの軸で読むための覚書。

公開頁: <https://syu-toutousai.github.io/seiji-doutai/>

## 四つの軸

1. **大きな政治と、身近な政治**
   - マクロ政治学（巨視的政治学）とミクロ政治学（微視的政治学）
   - 国・法・制度・大衆と、身体・情動・日常の相互行為
2. **平和の時と、戦いの時**
   - 平時モード（分散と対話、遅い決定）
   - 有事モード（集中と命令、速い決定）
   - 閾値を越える非線形な切り替わり
3. **力と情報の二つの次元**
   - 力（エネルギー）: 資源・物理力・インフラ
   - 情報: 記述・コード・伝達・サイバー空間
4. **文字で固めた枠と、土地のことば**
   - スクリプチュアル・マトリックス（文字とコードで固めた支配の枠）
   - ヴァナキュラー（土地の暮らしに根ざしたことばと営み）

四つは独立せず、平和の時には情報の次元が活発になり、危機の際には力の次元へ回帰する。構造（大きな政治・文字・力）と生成（身近な政治・暮らし・情報）の往還と相転移として編み直す。

## この頁の立場

完成した学説ではなく、対話と議論から生まれた見取り図である。歴史的な事例に当てはめる際には、資料に基づく検証と概念の精緻化が必要になる。図の配置や言い換えは理解のための便宜であり、固定的な定義ではない。
